# Voxsave 데모 영상 내레이션 대본 & 제작 노트

> **사용처**: 유튜브 데모 영상 / 홈페이지 임베드 / 소셜 미디어 짧은 영상
> **영상 길이**: 약 32~33초
> **자막 파일**: [demo.srt](demo.srt)
> **영상 소스**: [demo.html](demo.html) (브라우저에서 화면 녹화 → 영상 파일로 추출)

---

## 1. 내레이션 대본 (Voxsave로 음성 만들 때 이 텍스트를 그대로 붙여넣기)

```
Voxsave는 텍스트와 자막을 한국어 MP3로 바꿔주는 무료 데스크탑 앱입니다.

먼저 변환할 문장을 입력란에 적어줍니다.

미리듣기 버튼 한 번이면 바로 음성을 들어볼 수 있습니다.

미리듣기의 음질은 최종 저장 파일과 완전히 동일합니다.

마음에 들면 MP3로 저장 버튼을 누르고

저장 위치를 고르면 끝, 3초 만에 음성 파일이 완성됩니다.

이번엔 자막 파일을 통째로 음성으로 만들어 보겠습니다.

SRT 파일을 창에 끌어다 놓기만 하면 대사가 자동으로 추출됩니다.

타임코드, 번호, HTML 태그는 모두 자동으로 제거됩니다.

긴 자막도 한 번에 변환, 영화 한 편 분량도 거뜬합니다.

완료. 가입도, API 키도 필요 없는 완전 무료 도구입니다.
```

> 💡 **메타 팁**: 이 내레이션 자체를 Voxsave로 만들 수 있습니다.
> 위 텍스트를 Voxsave 텍스트 탭에 붙여넣고 SunHi 음성으로 저장하세요.
> "유튜브 데모 음성을 그 앱 자기 자신으로 만들었다"는 좋은 스토리가 됩니다.

## 3. 영상 제작 워크플로 (권장)

### A. demo.html을 영상 파일로 만들기
1. Chrome/Edge에서 `docs/demo.html` 열기
2. 화면 녹화 도구로 창 영역만 캡처 (33초 길이)
   - **ScreenToGif** (무료, Windows): GIF/MP4 추출
   - **OBS Studio** (무료, 모든 OS): 1080p MP4 권장
   - **NVIDIA ShadowPlay** (NVIDIA GPU 사용자)
3. 1920x1080 또는 1280x720 해상도, 60fps 권장 (자막 가독성)

### B. 내레이션 음성 만들기
1. **위 내레이션 대본**을 Voxsave 텍스트 탭에 붙여넣기
2. 음성: `SunHi · 여성` (또는 영상 톤에 맞춰 `InJoon · 남성`)
3. 속도: `+0%` (또는 -5% 천천히)
4. **MP3로 저장** → `demo_narration.mp3`

### C. 영상 + 음성 + 자막 합치기
- **다빈치 리졸브** (무료, 추천): 영상 트랙 + 음성 트랙 + SRT 자막 임포트
- **CapCut** (무료, 간단): 모바일 친화적
- **Adobe Premiere Pro** (유료)

순서:
1. 화면 녹화 영상을 메인 트랙에
2. `demo_narration.mp3`를 오디오 트랙에
3. 영상 길이에 맞춰 음성 속도 미세조정 (보통 ±5%)
4. `demo.srt`를 자막 트랙으로 임포트 → 폰트 24~32pt, 흰색+검정 외곽선
5. 마지막 1초에 "다운로드: github.com/cflab2017/Tool_Voxsave" 텍스트 오버레이

### D. 유튜브 업로드
- 제목 예: `자막 → MP3 30초, 한국어 TTS 무료 도구 Voxsave 시연`
- 설명에 다운로드 링크 + 블로그 글 링크
- 자막 업로드 시 `demo.srt` 그대로 사용 (자동인식 대신 직접 업로드 권장)

## 4. 짧은 버전 (15초 컷, 쇼츠/릴스용)

쇼츠나 인스타 릴스용은 Scene 2 만 사용 추천 (가장 임팩트 있음):

```
1
00:00:00,000 --> 00:00:03,000
영화 자막 파일 하나로
한국어 더빙 음성 만들기

2
00:00:03,000 --> 00:00:07,000
SRT 파일을 끌어다 놓으면
타임코드와 태그가 자동 제거됩니다

3
00:00:07,000 --> 00:00:11,000
저장 버튼 한 번에
긴 자막도 한 번에 변환

4
00:00:11,000 --> 00:00:15,000
가입, API 키 모두 필요 없는
완전 무료 무제한 도구입니다
```
